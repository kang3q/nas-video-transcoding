# nas-video-transcoding

NAS 에 있는 동영상을 재생 가능한 형태로 변환해 주는 도구입니다.

저장소에 두 세대가 있습니다.

| | 방식 | 상태 |
|---|---|---|
| **[v1](docs/v1.md)** | WebDAV 프록시. 플레이어의 요청을 보고 재생 의도를 추측해 변환 | 동결 (`v1.0.0`) |
| **v2** | 웹 UI. 사용자가 직접 폴더를 열고 파일을 골라 MP4 로 변환 | 개발 중 |

## 왜 v2 인가

v1 은 플레이어가 보내는 요청만 보고 "지금 재생하려는 것인지"를 알아내야 했습니다.
그게 되지 않았습니다 — 썸네일을 만들려고 파일을 여는 요청과 재생을 시작하는
요청이 **바이트 단위로 동일**합니다. 둘을 가르는 규칙을 세울 때마다 한쪽이
깨졌고, 마지막에는 폴더를 열자마자 재생을 누르는 정상적인 사용에서 재생이
실패했습니다.

v2 는 추측을 없앱니다. 웹에서 파일을 고르는 행위 자체가 의도이므로 알아낼 것이
남지 않습니다. 덤으로 진행률을 볼 수 있고, 변환이 끝나기 전에 결과를 확인해
잘못됐으면 나머지를 멈출 수 있습니다.

## 구조

```
ver1/    동결. 컴파일·테스트는 되지만 배포하지 않습니다
ver2/    개발 중
docs/    v1 문서
```

`ver2` 는 `ver1` 의 코드를 **컴파일 단계에서 import 할 수 없습니다** (`internal/`
규칙). 동결이 규율이 아니라 컴파일러로 보장됩니다.

디렉터리 이름이 `v1`/`v2` 가 아니라 `ver1`/`ver2` 인 이유는, Go 가
`모듈경로/v2` 를 "메이저 버전 2인 별개 모듈"로 해석하는 예약 패턴이기
때문입니다.
